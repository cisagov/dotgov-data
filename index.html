.gov Registry Data — Non-Production Copy

Search, sort, and filter the public list of registered .gov domains, published daily by the .gov registry. Data is read directly from the public GitHub repository — nothing is uploaded or stored elsewhere.

This is a prototype viewer for data published in the cisagov/dotgov-data repository. Built with Tabulator and PapaParse, both open source. To correct information about a domain you manage, sign in to the .gov registrar. Does not contain official .gov domain information. This repo supports the .gov registry team publishing data about the .gov zone — it's used to test format and publication changes before they ship, and may include fake .gov domains. Unless you're part of that team, this repo probably isn't useful to you.
